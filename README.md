# 🌎 South's Destination Page

South's Destination Page é uma página web criada para apresentar destinos turísticos do sul de forma atrativa, moderna e responsiva. O projeto utiliza uma combinação de HTML, CSS e JavaScript para oferecer uma experiência visual agradável e interativa.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** – estrutura e marcação semântica das seções da página.
- **CSS3** – estilização da interface, responsividade e efeitos visuais.
- **JavaScript (ES6+)** – adição de interatividade e manipulação dinâmica de elementos na página.

---

## 📌 Funcionalidades

- Página principal com destaques visuais para destinos turísticos.
- Design responsivo, adaptável para diferentes tamanhos de tela.
- Interatividade com JavaScript para uma navegação fluida e moderna.
- Layout simples, ideal para apresentações e divulgação de destinos.
